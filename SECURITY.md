# Security Policy

## Supported Versions

Currently, only the latest version of NetOrbit is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security-related bug (e.g., issues with privilege escalation or sensitive data handling), please report it privately:

1. Send an email to **[dallgatov@gmail.com]**.
2. Provide a detailed description of the vulnerability.
3. Include steps to reproduce the issue.

I will acknowledge your report within 48 hours and provide a timeline for a fix. 

Thank you for helping keep NetOrbit secure!
